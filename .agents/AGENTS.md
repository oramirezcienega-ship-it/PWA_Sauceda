# Reglas de Comportamiento - PWA SAUCEDA

## Control de Versiones (Git)
- Usar siempre la etiqueta `[skip ci]` al final de los mensajes de commit intermedios (`git commit -m "mensaje [skip ci]"`) para evitar disparar compilaciones y despliegues automáticos innecesarios en Netlify/Vercel.
- Omitir `[skip ci]` únicamente en el commit final o cuando el usuario indique expresamente que desea ver los cambios en productivo.
